# Sơn Son Mài Sắc (Demo Sơn Mài)

Website nghệ thuật tương tác tôn vinh nghệ thuật sơn mài truyền thống Việt Nam (*Sơn Son Mài Sắc*), phát triển bằng Next.js (App Router, TypeScript, Tailwind CSS, Lucide Icons).

## Các Trải Nghiệm Chính

- **Màn 01 - Khởi Đầu (Loading Experience)**: Cửa sổ mở ra không gian nghệ thuật sơn mài với bụi vàng quỳ chuyển động và âm hưởng trang trọng.
- **Màn 02 - Suy Ngẫm (Hero - Bạn Đang Nhìn Thấy Gì?)**: Bức tranh sơn mài son đỏ lấp lánh kết hợp nghệ thuật chữ khổ lớn mở ra câu hỏi về chiều sâu bên dưới lớp màu.
- **Màn 03 - Dẫn Nhập (Hook - Một Chiếc Hộp / Nhiều Lớp Sắc)**: Khám phá chiếc hộp sơn mài tinh xảo trong bóng tối với hiệu ứng điện ảnh.
- **Màn 04 - Bóc Tách Cấu Trúc (Case Study - Hành Trình Của Chiếc Hộp)**: Trực quan hóa bóc tách 6 lớp công đoạn thủ công đỉnh cao (*Nền/Vóc, Vẽ Nét/Họa Tiết, Dát Vàng/Bạc, Phủ Lớp/Ủ Sơn, Mài Nước/Đánh Bóng, Hoàn Thiện*).

## Cài Đặt & Chạy Dự Án

```bash
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000) trên trình duyệt để thưởng thức.
